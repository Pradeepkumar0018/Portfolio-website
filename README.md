# Pradeep Kumar — Portfolio

A lightweight, responsive portfolio for Pradeep Kumar, a 2026 B.Tech Computer Science and Engineering graduate from SRM Institute of Science and Technology.

## Run locally

This portfolio uses plain HTML, CSS, and JavaScript, so no package install or build step is needed. Open `index.html` in a browser, or serve the repository root with any static web server.

## Featured projects

- **CleanHub:** React/Vite/Tailwind service discovery and booking for laundry, vehicle, and shoe care. Includes a service advisor and booking history.
- **VibeWave Music:** React/Vite/Node/Express mood-based music discovery with a local catalog, experimental voice-emotion estimate, and favorites. It is not a music streaming service; playback opens Spotify when no preview is available.

## Deploy to Vercel

Connect this GitHub repository to Vercel. Select the **Other** framework preset, leave the build command blank, and serve the repository root, where `index.html` is located. The site is static HTML/CSS/JavaScript and needs no build step.
